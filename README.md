# ONG Apoio Solidário

Projeto acadêmico de desenvolvimento Front-End para apresentar uma ONG fictícia, seus projetos sociais e um formulário demonstrativo de voluntariado.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

- `index.html` — página inicial
- `projetos.html` — projetos sociais
- `cadastro.html` — formulário de voluntários
- `css/` — estilos
- `js/` — máscaras dos campos e envio demonstrativo
- `images/` — logo e fotografia em JPG e WebP

Abra o arquivo `index.html` em um navegador.
